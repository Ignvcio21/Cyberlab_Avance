# Nivel 5 — Objetivos de aprendizaje

## 1. Objetivo general

Desarrollar la capacidad de analizar el impacto real de un acceso obtenido mediante el mapeo del entorno interno, la identificación de posibilidades de movimiento lateral y escalada de privilegios, el análisis de exposición de datos y la documentación profesional del alcance completo del compromiso.

## 2. Objetivos específicos

### 2.1. Mapeo del entorno post-acceso
- Identificar qué hosts son accesibles desde el punto de compromiso inicial.
- Reconocer qué sesiones y conexiones existen en el sistema comprometido.
- Analizar el tráfico interno para detectar comunicaciones y patrones de infraestructura.

### 2.2. Análisis de escalada y persistencia
- Identificar indicadores de privilegios insuficientes y posibles vectores de escalada.
- Reconocer mecanismos que podrían permitir persistencia en el sistema.
- Evaluar si los controles de acceso del sistema comprometido son suficientes para contener un atacante con acceso inicial.

### 2.3. Evaluación de movimiento lateral
- Analizar qué otros sistemas son potencialmente accesibles desde el host comprometido.
- Identificar credenciales, tokens o configuraciones que podrían permitir acceso a sistemas adicionales.
- Comprender el concepto de "radio de explosión" de un compromiso: cuántos sistemas puede afectar un atacante con un solo punto de entrada.

### 2.4. Análisis de detección
- Evaluar si las acciones de post-explotación generan alertas detectables.
- Comprender qué técnicas de post-explotación son más silenciosas y por qué representan mayor riesgo.
- Relacionar la capacidad de detección del entorno con el nivel de riesgo que representa el acceso obtenido.

### 2.5. Documentación de impacto
- Cuantificar el impacto real del compromiso en términos de confidencialidad, integridad y disponibilidad.
- Redactar hallazgos de post-explotación con el nivel de detalle requerido en un reporte profesional.
- Formular recomendaciones de remediación específicas para cada hallazgo identificado.

## 3. Competencias que desarrolla este nivel

| Competencia | Descripción |
|---|---|
| Mapeo interno | Capacidad de analizar el entorno interno desde el punto de acceso obtenido |
| Evaluación de impacto | Capacidad de cuantificar el daño potencial real de un compromiso |
| Análisis de detección | Capacidad de evaluar la respuesta defensiva ante acciones ofensivas |
| Documentación avanzada | Capacidad de reportar hallazgos complejos con evidencia y recomendaciones |
| Criterio profesional | Capacidad de mantener límites éticos y operacionales bajo condiciones de acceso amplio |
